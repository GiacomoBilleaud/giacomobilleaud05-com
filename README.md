# Giacomo Billeaud Portfolio

This project is my personal portfolio website for ISDS 3100. The site was built using HTML and CSS and includes a main page, a resume page, and a project page. The purpose of the website is to present my skills, experience, projects, certifications, and contact information in a professional format for recruiters and employers.
## Live Websit
https://giacomobilleaud05.com/
## Reflection
One challenge I ran into was converting my original portfolio into the required three-page structure while keeping the design consistent across every page. I asked the AI agent to reorganize the site so that the main page included my profile, skills, experience, and contact information, while the resume and project sections were moved to separate pages. I also learned that each HTML page has to properly link to the same stylesheet and that navigation links must point to the correct file paths. This helped me better understand how multiple HTML pages work together as one website. Another thing I learned is how to push websites from the terminal to GitHub and buy domains.
